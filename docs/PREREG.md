# Pre-registration — Neuralese Diffusion v1

Frozen **before** `tools/eval.mjs` was run on the trained weights (2026-10-26, PT). The SHA-256 of this file is recorded in
`results/summary.json` and in CLAIMS.md; edits after the run would change the hash. Thresholds are not tuned afterwards.

**Setup (all hypotheses).** Four tiny class-conditional ε-prediction UNets (≈630 k params each, identical architecture,
T = 200, linear β 1e-4→0.02), one per modality: `image` (MNIST 16×16, 10 classes), `music` (piano-roll 16×32, 4 patterns),
`video` (4-frame 16×16 moving blob, 4 directions), `shape3d` (64-point clouds as 3×8×8, 4 shapes). Sampling runs the
shipped JS engine (`site/engine.js`) in Node. N = 40 samples per condition, class = i mod K, seed = 1000 + i,
DDIM 20 steps, classifier-free guidance g = 3 unless stated. **Judge** = the tiny CNN classifier shipped with each model,
trained on clean data only (it never sees generated samples). Caveat: a judge trained on the same distribution is a weak
proxy for "real" quality; it measures whether the requested class is recognisable.

| id | hypothesis | metric | supported if | 
|---|---|---|---|
| H1 | Guidance makes the condition matter | judge accuracy vs requested class | acc(g=3) ≥ 0.80 **and** acc(g=3) − acc(g=0) ≥ 0.40 |
| H2 | Coarse-to-fine: class identity is decided early | judge class of the x̂₀ lens at the first step with t ≤ 0.6·T vs final judged class | agreement ≥ 0.70 |
| H3 | Patching the bottleneck matters more early than late | source class a, target class (a+1) mod K, same seed; patch the post-attention bottleneck from the source run at t ≥ T/2 ("early") vs t < T/2 ("late"); flip rate = judge says a | flip(early) − flip(late) ≥ 0.30 |
| H4 | A mean-difference steering vector controls the class | unconditional sampling (null class) + α·(μ_target − μ_all) added to the bottleneck at all steps, α = 4 | target hit rate ≥ 0.50 (chance = 1/K) |
| H5 | The bottleneck linearly encodes class at t = T/2 even with the null label | linear probe, held-out noised data | accuracy ≥ 2/K |
| H6 | DDIM-20 matches DDPM-50 | judge accuracy at g = 3 | \|acc(DDIM20) − acc(DDPM50)\| ≤ 0.10 |
| H7 | Class information flows through cross-attention | zero the cross-attention output projection (`ca.o.weight`, `ca.o.bias`), then sample | accuracy drop ≥ 0.30 vs H1 g = 3 |
| H8 | (video only, judge-free) motion direction is right | centroid displacement frame 0→3 of the generated clip, sign of the dominant axis | direction accuracy ≥ 0.80 |
| H9 | (shape3d only, judge-free) the shape is right | nearest class by Chamfer distance to 16 fresh reference clouds per class (generated by the JS port of `data.py`) | accuracy ≥ 0.60 |

A hypothesis is reported ● supported / ○ not supported per modality. Negative results stay in CLAIMS.md.
